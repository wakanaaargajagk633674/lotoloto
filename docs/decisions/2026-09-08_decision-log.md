# Math Core Rebuild Decisions

Date: 2026-09-08

## Decisions

1. 予想アルゴリズムの中核を「検定・導出できる計算」に置き換える (`src/loto/mathCore.ts`)。
   当せん確率は選び方で変わらないため、数理的に最適化できる対象を「当せん時の期待受取」と
   「複数口の被覆」の2つに限定する。
2. 出現頻度シグナルはカイ二乗検定に基づく James–Stein 縮小 (λ = max(0, 1 − dof/χ²)) でゲートする。
   実データでは λ = 0 (p = 0.92 / 0.82) なので、hot / cold はテーマとしての下限 0.35 倍だけ残す。
3. 2026-07-31 に設計した経験的人気度推定は、データに販売額が無いため実際には一度も動いていなかった。
   固定賞金等級の当せん口数 ÷ 理論確率で販売口数を復元し、Ridge 回帰 (λ = 4) で数字ごとの対数人気度 β を
   推定する方式に置き換える。事前分布との合成 (n/(n+200)) は維持する。
4. 1等の期待受取係数は Poisson 近似の閉形式 E[1/(1+X)] = (1 − e^{−m})/m で計算し、
   ヒューリスティックな人気度指数と 50:50 で合成する。回帰は数字単体しか見ないため、並びのクセは指数側に残す。
5. 参照等級 (3個 / 4個一致) の β は 1等向けに mainCount/matches 倍で一次補正する。
   これは近似であり、過大評価を避けるため合成比率を 50% に留める。
6. 複数口では 3 個組の被覆率を候補評価に加点 (0.15)。既存の usedPairs ペナルティは残す。
7. 分析 JSON (`data/analysis/*_analysis.json`) に一様性検定、推定口数、回帰 β を出力し、
   バックテスト集計に `averagePayoutFactor` と `tripleCoverageRatio` を追加する。
8. 「世界一の強運」「天文学的」といった表現はプロダクト文言に入れない。AGENTS.md の Product Safety を優先する。
