# 2026-09-14 ロト7 実験ラボ 判断記録

1. **予測力の判定基準を AUC + BH 補正 + 乱数対照に固定した。** top7 一致数だけでは 594 回で検出力が足りず、選択効果で「最良角度」が必ず出る。全順位を使う AUC と、同条件の乱数 20 本の分布を基準にした。
2. **有意な角度が無い場合の 3 口の決め方。** 「当たりやすい数字」は存在しないと判定されたため、口1 は標本外上位 5 角度の順位平均 (根拠は弱いと明記)、口2 は数理的に唯一 EV に効く期待受取係数の最大化、口3 は折衷とした。既存の高配当理論 (Poisson 近似) をそのまま流用。
3. **構造制約は「除外」ではなくフィルタ。** 合計 100-166 / 奇数 2-5 / 連番 ≤2 は理論分布の中央 ~80% を選ぶだけで、確率を変えない。レポートにもその旨を記載。
4. **並べ替え検定は抽せん順序のシャッフル。** 周辺頻度を保ったまま時間構造だけを壊すので、hot_all のような周辺依存の角度では perm p と解析 p の意味が異なる。レポートに注記。
5. 既存の予想エンジン・UI・重みは変更しない。ラボは独立モジュールとして追加のみ。
