# Analysis Site UX

Date: 2026-06-25 JST

## コンセプト

lotolotoは「買い目アプリ」ではなく、「ロト6ロト7の過去データを見やすく分析するサイト」として設計する。

既存の爽やかなライトUIを維持し、黒背景、ネオン、カジノ風、情報商材風の表現は避ける。

## トップページの役割

トップページでは参考買い目生成を主役にしない。主役は以下。

- サイト概要
- ロト6 / ロト7分析ページへの導線
- 最新結果
- 分析対象回数
- データ更新状況
- CSVダウンロード
- データソースと公式照合状況

参考買い目生成は `/prediction` に残し、ナビゲーション上でも最後に置く。

## 見せ方の原則

- すべての数値にラベルと単位を付ける。
- `06 (326)` のような、意味が分からない括弧表記は使わない。
- 各表に「この表の見方」を付ける。
- 出現回数や未出現期間は、未来予測ではなく過去傾向として説明する。
- スマホでは表を横スクロールにし、カードは1カラムにする。
- CSVダウンロードボタンを分析セクションに置く。

## 注意文

「本サイトは、ロト6ロト7の公開データを整理分析する情報サイトです。当せん番号の予測や当せんを保証するものではありません。」

パターン参考:

「過去の並び方や数字の組み合わせを参考にした情報であり、数字を除外したり当せんを保証したりするものではありません。」

キャリーオーバー:

「キャリーオーバーは配当面に影響する場合がありますが、当せんしやすくなるものではありません。」
