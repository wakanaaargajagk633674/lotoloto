# LOTOLOTO Light Insight UX Concept

## Concept

LOTOLOTO Light Insight

「数字を、やさしく読み解く。」

## Product Positioning

Lotoloto は、宝くじの当せん番号を予測保証するサイトではない。ロト6・ロト7の過去データを、出現回数、間隔、組み合わせバランス、分配リスクの観点で整理し、初めての人にも分かる参考買い目として表示するライトな分析サービスである。

## Desired Impression

- 爽やか
- 明るい
- 清潔感
- 安心感
- 親しみやすい
- 見やすい
- 怪しくない
- ギャンブル感が薄い
- 公共サービスや家計簿アプリに近い信頼感
- 初心者でも意味が分かる
- スマホで読みやすい
- 毎週開きたくなる軽さ

## Avoid

- 黒背景中心
- ネオン
- カジノ風
- 暗号資産トレード画面風
- 怪しい予想サイト風
- 情報商材風
- AIで当てます風
- 数字だらけ
- 説明のないスコア
- 何の数字か分からない括弧表記

## Voice

やさしい分析サービスとして話す。

- Use: 参考買い目、過去傾向、出現回数、前回からの間隔、候補バランス調整、分配リスクを意識、ランダム性を残す、過信せず楽しむ
- Avoid: 的中率アップ、必勝、当選確実、爆当たり、神予想、買わないと損、AIが当てる

## Number Display Rule

数字の後ろに括弧だけで回数やスコアを置く表記は禁止する。

Use:

- 数字 06
- 過去出現回数: 326回
- 集計範囲: 全期間

All metrics must have a label, unit, and short explanation where practical.

## Pattern Reference Language

参考サイトでは特定候補を除外する考え方が紹介されている。本プロジェクトでは、この考え方を直接的な除外ではなく、候補の優先度を調整する soft signal として扱う。

UIでは以下を使う。

- パターン参考
- 候補バランス調整
- 低優先候補
- 組み合わせバランス
- 参考フィルター
