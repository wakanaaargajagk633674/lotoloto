# LOTOLOTO Intelligence UX Concept

## Concept

LOTOLOTO Intelligence

「数字を選ぶ」から「数字を読み解く」へ。

## Product Positioning

Lotoloto は、宝くじの当せん番号を予測保証するサイトではない。ロト6・ロト7の過去データを読み解き、頻度、間隔、組み合わせバランス、人気回避傾向を整理して、参考買い目を生成する分析ダッシュボードである。

## Desired Impression

- かっこいい
- おしゃれ
- 見やすい
- 信頼できる
- 怪しくない
- 未来感がある
- 数字選びが楽しい
- スマホでも気持ちよく使える
- データ分析アプリとして説得力がある
- ギャンブル煽りではなく、知的な分析体験に見える

## Avoid

- 昔の宝くじ予想サイト風
- 原色だらけ
- 点滅や派手な当たり演出
- 情報商材っぽいコピー
- 怪しい占いサイト風
- 「的中」「必勝」を連想させる煽り

## Voice

信頼感のある分析ツールとして話す。

- Use: 参考買い目、過去傾向、分析結果、候補調整、バランスを見る、分配リスクを意識、ランダム性を残す、過信せず楽しむ
- Avoid: 的中率アップ、必勝、当選確実、爆当たり、神予想、買わないと損

## Pattern Filter Language

参考サイトでは特定候補を除外する考え方が紹介されている。本プロジェクトでは、この考え方を直接的な除外ではなく、候補の優先度を調整する soft signal として扱う。

UIでは以下を使う。

- 候補調整
- パターンフィルター
- 低優先候補
- 組み合わせバランス
- 参考フィルター
- トレンドフィルター
- セレクション調整
