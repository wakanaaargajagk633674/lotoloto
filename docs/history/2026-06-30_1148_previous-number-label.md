# Previous Number Label Display

Date: 2026-06-30 11:48 JST

## Scope

- Added a ticket-number label for numbers that appeared in the previous main draw.
- The label is displayed as `（前回出現数字）`.
- Adjusted number button sizing and wrapping so the longer label fits on desktop and mobile.

## Safety

- This is a display-only change.
- The label does not claim that previous numbers are more likely to win.
- Existing prediction scoring behavior is unchanged in this task.
