# 2026-09-14 13:30 ロト7 実験ラボ構築と第695回向け 3 口決定

## 依頼

次回ロト7の数字を「様々な角度から徹底的に実験検証を繰り返して」3 口決める。

## 実施

- `src/loto/lab.ts` を新設。40 角度 (頻度 8 系 + 窓 6×2、EWMA 4×2、縮小事後、間隔 4、直前回 4、遷移 2、レジーム 2、構造 5) と乱数対照 20 本を、
  同一のウォークフォワード条件 (学習 100 回 → 標本外 594 回) で採点する `LabState` 増分統計エンジンを実装。
- 主指標は Mann–Whitney AUC (帰無 0.5、解析的分散で z/p)。補助に top7 一致数 (超幾何帰無 1.324)、top10/15/20 被覆、前後半一致。
- 全 60 角度に Benjamini–Hochberg 補正。抽せん順序シャッフル 200 回の並べ替え検定で時間構造を分離。
- 合計・奇偶・連番・低域個数・レンジ・一の位重複の 6 構造を、一様抽せんの Monte Carlo 理論分布と χ² 検定。
- `scripts/run-loto7-lab.ts` (`npm run lab:loto7`) で結果を `data/backtest/loto7-lab/` と `docs/backtest/loto7-lab-report.md` に出力。
- `tests/lab.test.ts` 7 件追加 (一様データで有意ゼロ、植え込んだ偏りは検出、状態更新の整合)。

## 結果

- 構造 6 検定はすべて p ≥ 0.05。過去の合計・奇偶分布は組合せ論の理論値と一致。
