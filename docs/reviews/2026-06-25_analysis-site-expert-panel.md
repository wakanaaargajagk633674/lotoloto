# Analysis Site Expert Panel Review

Date: 2026-06-25 JST

対象: lotolotoを「参考買い目生成」中心から「ロト6ロト7過去データ分析サイト」中心へ拡張する判断。

## 1. 確率論者

- 肯定: 過去データを整理することは、ランダム抽せんの分布を理解する助けになる。
- 否定: 出現回数を未来予測として見せると誤解を生む。
- 斜め上の代替案: ランダム性を体感する教材としての価値を前面に出す。
- 最終判断: 出現回数、分布、理論確率を掲載する。
- 採用理由: データ理解に役立つ。
- 不採用理由: 「次に出る数字」とは表現しない。
- 次に検証すべきこと: 理論期待値との差を可視化する。

## 2. 統計学者

- 肯定: 頻度、合計値、奇数偶数、連番の集計は分析サイトとして有用。
- 否定: 小さな偏りを法則のように扱うのは危険。
- 斜め上の代替案: カイ二乗検定や平均との差を「普通のブレ」として表示する。
- 最終判断: 現段階では記述統計を中心にし、断定表現を避ける。
- 採用理由: 初心者にも分かりやすい。
- 不採用理由: 有意性を断定する高度分析は未実装。
- 次に検証すべきこと: 期待値との差と期間別安定性。

## 3. データエンジニア

- 肯定: 公式データと外部履歴データを照合し、CSVを公開する価値が高い。
- 否定: データソースや取得日時がないCSVは信用されない。
- 斜め上の代替案: データ品質レポートをサイトコンテンツ化する。
- 最終判断: 公式CSV取得、sougaku履歴、品質レポート、CSV公開を実装する。
- 採用理由: 分析サイトとしての信頼性が上がる。
- 不採用理由: 公式から取得できない全期間を公式扱いしない。
- 次に検証すべきこと: 差分の項目別分類とUI表示。

## 4. 宝くじ制度調査担当

- 肯定: 販売実績、キャリーオーバー、等級別口数は配当面の理解に必要。
- 否定: 当せん番号だけでは分析サイトとして浅い。
- 斜め上の代替案: 当せん確率と分配リスクを分けて説明する。
- 最終判断: キャリーオーバー、販売実績、等級別配当を表示する。
- 採用理由: 公式データの価値を活かせる。
- 不採用理由: 配当が当せんしやすさを変えるとは表現しない。
- 次に検証すべきこと: キャリーオーバー時と非発生時の配当差。

## 5. 行動経済学者

- 肯定: 誕生日数字や31以下偏りは分配リスクの参考になる。
- 否定: 人気数字を避けても当せん確率自体は変わらない。
- 斜め上の代替案: 「人と被りやすいか」という観点で説明する。
- 最終判断: 分配リスクは参考情報として扱う。
- 採用理由: 高配当狙いページの説明と整合する。
- 不採用理由: 当たりやすさとは結びつけない。
- 次に検証すべきこと: 実際の口数分布データが取得できるか。

## 6. UXデザイナー

- 肯定: 分析ページに「この表の見方」を入れると初心者が理解しやすい。
- 否定: 表と数字だけを大量に並べると古い予想サイトに見える。
- 斜め上の代替案: まず最新結果とCSV導線を見せ、詳細はタブ化する。
- 最終判断: ライトUI、カード、説明文、横スクロール表を採用する。
- 採用理由: 爽やかで安心感のある分析サイトになる。
- 不採用理由: 黒背景やネオン表現には戻さない。
- 次に検証すべきこと: モバイルでの表閲覧体験。

## 7. 懐疑派数学者

- 肯定: 法則がないことを確認する分析にも価値がある。
- 否定: 出現ランキングを買うべき数字に見せるのは不適切。
- 斜め上の代替案: ランダムとの差を常に添える。
- 最終判断: 過信防止文を各分析に配置する。
- 採用理由: 疑似科学化を避けられる。
- 不採用理由: 的中率向上の断定はしない。
- 次に検証すべきこと: バックテストレポートのサイト表示強化。

## 8. データ可視化専門家

- 肯定: 棒グラフ、分布、ランキングは情報を把握しやすい。
- 否定: 色を増やしすぎると意味が伝わらない。
- 斜め上の代替案: 順位だけでなく、平均との差を追加する。
- 最終判断: 現段階は棒グラフと表を中心にする。
- 採用理由: 実装負荷を抑えつつ見やすい。
- 不採用理由: 派手な可視化やアニメーションは避ける。
- 次に検証すべきこと: ヒートマップと期待値差グラフ。

## 9. 法務コンプライアンス担当

- 肯定: 過去データ分析サイトとしてなら健全に見せられる。
- 否定: 「当せん確実」「的中率アップ」「勝てる」表現は避けるべき。
- 斜め上の代替案: 各ページに短い免責を自然に入れる。
- 最終判断: 共通注意文と分析別注意文を配置する。
- 採用理由: 誤認リスクを下げられる。
- 不採用理由: 注意文を小さく隠さない。
- 次に検証すべきこと: 全ページ文言監査。

## 10. プロダクトマーケター

- 肯定: CSVダウンロードと分析ページは検索流入と再訪に強い。
- 否定: 買い目だけのサイトは一度使って終わる可能性が高い。
- 斜め上の代替案: 週次分析サマリーを作る。
- 最終判断: トップページを分析サイト中心にし、参考買い目は補助導線にする。
- 採用理由: 長期的なコンテンツ価値がある。
- 不採用理由: 買い目訴求を主役にしない。
- 次に検証すべきこと: 週次更新導線とSEOタイトル。

## 最終判断

- 採用するもの: 分析サイト中心のトップ、ロト6/ロト7分析ページ、CSVダウンロード、公式照合、専門家レビューコンテンツ。
- 採用しないもの: 当せん保証、的中率向上表現、黒背景ネオンUI、説明なし括弧表記。
- 保留するもの: 期待値差グラフ、カイ二乗検定、週次サマリー自動生成。
- 次の検証: 主要ページのHTTP 200、スマホ表示、CSV列のExcel互換性、公式差分の項目別UI表示。
