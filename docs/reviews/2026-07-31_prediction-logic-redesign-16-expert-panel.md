# 予想ロジック再設計 16人専門家パネル

Date: 2026-07-31

参加: 数学者(組合せ論)、ベイズ統計家、パリミュチュエル理論家、データサイエンティスト、計量経済学者、
行動経済学者、認知心理学者、統計的検定担当、最適化アルゴリズム設計者、ポートフォリオ理論家、
UX/プロダクト設計者、法務(景表法)、依存対策担当、ソフトウェアアーキテクト、QA、占い師(数秘・九星気学)。

## 出発点となった実測

第2124回までのウォークフォワード結果で、pure_random が全ての「分析系」戦略を
平均一致数・3個以上一致率・1口あたり払戻のすべてで上回っていた。
理論期待値は 6×6/43 = 0.837 で、各戦略の差はいずれも誤差の範囲。
つまり分析系シグナルには当せん確率上の優位がなく、候補プールを狭める分だけ分散を増やしていた。

## 主な対立と結論

### 候補プールの絞り込み

- 数学者: 43個中24個に絞るのはエントロピーの純損失。
- ベイズ統計家: 期待一致数は不変であり「純損失」は不正確。増えるのは分散。
- 決着: 期待値は不変、分散が増えるだけで見返りがないため撤廃。全数字を候補に残し、
  好みは重み付き抽出で表現する。

### 人気度の推定方法

- データサイエンティスト: 「31以下は人気」という決め打ちをやめ、5等口数と販売額から推定できる。
- 計量経済学者: キャリーオーバーや時期による交絡があるため、販売口数で正規化し回ごとに標準化すべき。
  また1回に6個の数字が同時に効くので素朴な平均には相互汚染がある。
- データサイエンティスト: 43変数の回帰は過学習の恐れ。事前分布とのシュリンケージで妥協。
- 決着: 事前分布 + 経験推定を信頼度 n/(n+200) で合成。

### 事前分布の中身

- 行動経済学者: 1-12 が最頻(月と日の両方に使える)、13-31 が次点、32以上は激減。
  日本市場では 7・8・3 が選ばれやすく 4・9 は避けられる。連番は「ランダムらしくない」と
  誤解されて避けられるため、含むと重なりにくい。
- 認知心理学者: 等差数列、同じ下1桁、中央付近の合計値はマークシート上で集中しやすい。
  これらは数字単体の平均では捉えられないので組み合わせレベルで評価すべき。
- 占い師: 数秘の吉数凶数は抽せん結果には影響しない。ただし「多くの人がそう信じている」という
  購買者行動の事実としては有効。予測ではなく他者の行動予測として使うべき。
- 数学者: その変換なら行動経済学の議論と整合する。事前分布の一項として採用に賛成。
- 統計的検定担当: 経験データで検証され、否定されればシュリンケージで自動的に消える設計なら許容。

### 検証可能性

- 統計的検定担当: 人気度モデルを作るだけでは信仰にすぎない。買い目の推定人気度を
  バックテストの出力メトリクスに加え、実払戻との関係を追えるようにすること。
- 決着: `averageCombinationPopularityIndex` と `selectionEntropyGap` を summary に追加。

### 分析系シグナルの扱い

- 最適化担当: 根拠のないシグナルで周辺分布を歪めるのは分散だけ増やす。
- ポートフォリオ理論家: 宝くじ購入者の効用は凸なので分散増が常に悪とは限らない。
  ただし無自覚な分散増は最悪で、増やすなら意図的に。
- UX担当: 全部ランダムに寄せるとサイトの存在意義が消える。削除ではなく正直な位置づけに。
- 法務: 優良誤認回避の観点から、表示文と実装の影響度を一致させることは必須。
- 決着: シグナル予算(合計 0.62 以下)と中立ブレンドを導入し、影響度を明示的に管理。
  戦略は残し、説明文を「当たりやすさは変わらない」旨に統一。

### 実装上の制約

- アーキテクト: バックテストは 1,824ステップ×7戦略。人気度推定は履歴長でメモ化必須。
  ウォークフォワードの原則上、推定はその時点までの履歴のみを使うこと。
- QA: 未来データ不参照、周辺分布の一様性、重みの境界、再現性のテストを要求。

## 全員一致の留意事項

期待値は還元率の分だけ必ず購入額を下回る。人気度を避けても当せん確率は変わらず、
変わりうるのは当せんした場合の分配人数の目安だけである。
この点は説明文とドキュメントの両方で明示する。
