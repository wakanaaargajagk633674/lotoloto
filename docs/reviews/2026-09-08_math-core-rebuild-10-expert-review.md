# 数理コア再設計 10人専門家レビュー

Date: 2026-09-08

参加: 組合せ論数学者、ベイズ統計家、統計的検定担当、パリミュチュエル理論家、計量経済学者、
最適化アルゴリズム設計者、ポートフォリオ理論家、ソフトウェアアーキテクト、QA、法務(景表法)。

## 出発点

ユーザー要望は「数学的に予想アルゴリズムを組み直す」。抽せんはランダムで当せん確率は改善できないため、
数理的に扱える対象を (a) 頻度シグナルの根拠の検定、(b) 当せん時の期待受取、(c) 複数口の被覆 に限定した。

## 指摘と対応

- 統計的検定担当: 「hot/cold を使うなら検定で根拠を示せ」→ カイ二乗 p = 0.92 / 0.82。根拠なしと確認し、λ = 0 で自動的に消えるゲートを導入。
- ベイズ統計家: 縮小率を手調整 (neutral_blend) ではなくデータから決めるべき → James–Stein 型 λ を採用。neutral_blend は互換のため残す。
- パリミュチュエル理論家: 販売額が無いのに「口数で正規化」と書かれていた旧実装は死んでいた → 固定賞金等級から口数を復元。推定 ≈ 664万口 / 645万口は公表水準と整合。
- 計量経済学者: 数字ごとの人気を平均ではなく回帰で同時推定すべき → Ridge 回帰。事前分布と独立に 11, 8, 3, 12, 7 が上位、32以上が下位に出た。
- 組合せ論数学者: 3個一致の β を 1等にそのまま使うと過小評価 → mainCount/matches 倍で一次補正し、合成比率 50% で過大評価も抑制。
- 最適化設計者: 期待受取は閉形式で → Poisson 近似 E[1/(1+X)] = (1 − e^{−m})/m。
- ポートフォリオ理論家: 複数口は 3 個組の被覆で散らす → tripleCoverageRatio を加点。
- アーキテクト: 既存の戦略・重み・UI を壊さない → 型の追加のみで既存テスト 16 件は無変更で通過。
- QA: 合成データで回帰が植え込んだ人気数字を復元できるか → tests/mathCore.test.ts に 9 件追加。
- 法務: 「強運」「天文学的」などの表現は使わない → 文言は「当せん時の同時当せん期待人数」に限定。

## 結論

可決 (10/10)。当せん確率の主張は一切増やさず、数理的に検証可能な部分だけを強化した。
