# UX Safety Rules

## Required Copy

Always show:

> この予想は過去データの傾向をもとにした参考買い目です。当選番号を保証するものではありません。

For high-payout mode:

> 高配当狙いは、当たりやすさではなく、当選時に他の購入者と数字が重なりにくくなる可能性を重視したモードです。

For sougaku deletion-number mode:

> 削除数字は過去傾向から候補を絞る考え方ですが、当選確率の向上を保証するものではありません。本アプリでは検証可能なスコアとして扱います。

## Do Not Use

- 必ず当たる
- 的中率アップ保証
- 勝てる数字
- そろそろ出る
- 出ない数字だから除外して安全

## UI Principles

- Make the actual generator the first screen.
- Show game, strategy, ticket count, result, reasons, dashboard, backtest summary, and warnings.
- Keep scores labeled as relative strategy scores.
- Include budget-aware, non-sensational wording.
