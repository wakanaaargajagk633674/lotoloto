# UX Safety Rules

## Required Copy

Always show:

> このサービスは、過去データをもとに参考情報を整理するものです。当せん番号を予測保証するものではありません。

For high-return mode:

> ハイリターンは、当たりやすさではなく、当選時に他の購入者と数字が重なりにくくなる可能性を重視したモードです。

For pattern-filter mode:

> このフィルターは、過去データの並び間隔バランスを参考に候補の優先度を調整するものです。当選確率の向上を保証するものではありません。

For number-level candidate tuning:

> 過去傾向から、今回の組み合わせでは優先度を少し下げた数字です。除外や的中保証を意味するものではありません。

## Do Not Use

- 必ず当せんする
- 的中率アップ保証
- 勝てる数字
- そろそろ出る
- 出ない数字だから安全
- 激アツ
- 当選確実

## UI Principles

- Make the actual generator and dashboard the first screen.
- Show game, strategy, ticket count, result, reasons, dashboard, backtest summary, and warnings.
- Keep scores labeled as relative strategy scores.
- Include budget-aware, non-sensational wording.
- Present LOTOLOTO Light Insight as a friendly data-analysis experience, not a prediction-sales site.
